发布步骤

  1. 在本页编辑内容并下载对应 JSON 文件。
  2. 点击顶部 GitHub 编辑按钮，登录 GitHub 后用下载文件的内容替换原内容。
  3. 点击 GitHub 页面底部的“Commit changes”。
  4. 等待 Netlify 部署完成，通常几分钟内生效。
