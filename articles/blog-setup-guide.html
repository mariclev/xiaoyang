从零配置个人博客：GitHub + Netlify 部署完整教程与踩坑记录

这篇文章记录“小羊半夏的温馨小家”的完整搭建过程，包括 GitHub 管理代码、Netlify 自动部署、常见错误处理，以及如何继续扩展日记、头像和个人资料功能。

一、为什么搭建个人博客

相比朋友圈和临时笔记，个人博客可以长期沉淀自己的技术路线。对于嵌入式开发者来说，可以记录 STM32、FreeRTOS、传感器、电机控制、AI 工具使用经验，让别人通过搜索了解自己的能力。

二、准备开发环境

  • Git：管理代码版本。
  • Node.js：运行前端工具。
  • Netlify CLI：完成命令行部署。

三、遇到的第一个问题：node 命令无法识别

node : 无法将“node”项识别为 cmdlet、函数、脚本文件或可运行程序的名称。

原因通常是没有安装 Node.js，或者环境变量 PATH 没有刷新。

解决方法：

winget install --id OpenJS.NodeJS.LTS

安装完成后重新打开 PowerShell：

node -v
npm -v

四、GitHub 管理博客代码

git clone 仓库地址
git pull origin main
git status
git push origin main

每一次修改都可以通过 Git 保存，方便恢复历史版本。

五、Netlify 部署流程

netlify login
netlify link
netlify deploy --dir .
netlify deploy --prod --dir .

netlify deploy 用于预览测试，确认页面正常后，再使用 --prod 发布正式网站。

六、常见错误

1. You don't appear to be in a folder that is linked to a project

说明当前目录没有绑定 Netlify 项目。进入博客根目录后执行：

netlify link --id 项目ID

2. 页面更新但是浏览器还是旧内容

尝试 Ctrl + F5 强制刷新，或者清理浏览器缓存。

3. 图片无法显示

检查路径。Netlify 静态部署建议使用相对路径，例如：

assets/avatar.svg

七、给博客增加日记和个人资料

静态博客也可以拥有简单交互功能。本网站使用 localStorage 实现：

  • 写日记
  • 修改头像
  • 修改说说
  • 修改个人签名
  • 导出和恢复日记备份

这些数据保存在浏览器本地，不需要服务器和数据库，适合个人记录。
