ADC 基础：模拟量如何变成数字量

先用生活中的“刻度尺”理解 ADC，再进入分辨率、采样时间、参考电压、滤波与硬件抗干扰。

📅 2026-08-04🐑 小羊半夏⏱ 计算中
#STM32#ADC#基础知识

一、为什么单片机需要 ADC

现实世界中的温度、压力、声音、光照和电压通常连续变化，这类信号叫模拟信号。单片机内部处理的是离散数字，因此需要 ADC 把某一时刻的模拟电压转换成数字值。

ADC 可以理解成一把带有固定刻度的尺子：它无法表示无限精细的电压，只能把输入电压归到最接近的刻度。

二、模拟信号和数字结果

假设参考电压为 3.3 V，ADC 的输入范围也是 0～3.3 V。输入 0 V 时结果接近 0；输入接近 3.3 V 时结果接近满量程。中间电压则按照比例转换。

ADC 数字值 ≈ Vin ÷ Vref × (2ⁿ − 1)

其中 n 是 ADC 位数。12 位 ADC 共有 4096 个可能的数字状态，通常使用 0～4095 表示。

三、分辨率怎么计算

分辨率表示数字值变化 1 个计数大约对应多少输入电压。以 3.3 V、12 位 ADC 为例：

每个计数 ≈ 3.3 V ÷ 4096 ≈ 0.806 mV

这并不等于实际系统一定能稳定分辨 0.806 mV。电源噪声、参考电压误差、布线和 ADC 本身误差都会降低有效精度。

四、ADC 内部经历了什么

1. 采样

ADC 在指定时刻连接输入信号，并给内部采样电容充电。

2. 保持

采样开关断开后，采样电容暂时保持这次电压，让后级有时间完成比较和转换。

3. 量化

连续电压被映射到有限的数字等级，因此天然存在量化误差。

五、为什么采样时间很重要

传感器输出并不是理想电压源。如果信号源阻抗较高，而采样时间太短，ADC 内部电容来不及充到真实输入电压，读数就可能偏低或不稳定。

判断方向：降低采样速度或增加采样时间后，如果读数明显改善，应重点检查信号源阻抗、前级 RC 网络和芯片手册中的采样要求。

六、参考电压决定测量基准

ADC 的结果是输入电压相对于参考电压的比例。如果参考电压本身发生波动，即使输入信号完全不变，转换结果也会改变。

  • 模拟电源附近需要正确放置去耦电容。
  • 参考电压走线应远离高速开关节点。
  • 模拟地和数字回流路径需要合理规划。
  • 不能只看标称 3.3 V，应关注负载变化和纹波。

七、STM32 ADC 的基础流程

不同 STM32 系列的寄存器和库函数会有差别，但总体步骤相似：

  1. 打开 GPIO 和 ADC 外设时钟。
  2. 把引脚配置为模拟输入模式。
  3. 设置 ADC 分辨率、通道和采样时间。
  4. 按需要执行校准。
  5. 启动转换并等待完成，或使用 DMA 自动搬运数据。
  6. 把数字值换算成电压或物理量。
// 通用示意代码，具体接口以所用 STM32 系列为准
uint16_t adc_raw = adc_read_channel();
float voltage = (float)adc_raw * 3.3f / 4095.0f;

八、软件滤波能解决什么

连续采集时，数字值发生少量跳动很常见。可以根据需求使用平均值、中值、限幅或低通滤波，但软件滤波不能替代正确的硬件设计。

// 简单的 N 点平均示意
uint32_t sum = 0;
for (int i = 0; i < N; ++i) {
    sum += adc_read_channel();
}
uint16_t average = sum / N;
  • 平均滤波：适合随机小幅噪声，但会增加延迟。
  • 中值滤波：适合偶发尖峰。
  • 低通滤波：适合缓慢变化的物理量。
  • 过采样：在噪声和条件合适时可改善有效分辨率。

九、PCB 和接线注意事项

  • ADC 输入线尽量短，远离 PWM、电机和时钟线。
  • 传感器地线应有清晰回流路径，避免与大电流回路共用狭窄走线。
  • 去耦电容靠近芯片对应电源引脚放置。
  • 外部长线输入应考虑限流、钳位和静电防护。
  • RC 滤波参数需要兼顾带宽与采样建立时间。

十、读数异常时的排查顺序

  1. 用万用表或示波器确认 ADC 引脚真实电压。
  2. 确认引脚模式、通道号和参考电压配置。
  3. 延长采样时间并降低采样频率观察变化。
  4. 检查电源纹波、地线压降和周围开关噪声。
  5. 最后再调整滤波算法和换算公式。
学习总结：ADC 读数是“输入信号、参考电压、采样电路、PCB 和软件处理”共同作用的结果，不能只从代码寻找原因。
