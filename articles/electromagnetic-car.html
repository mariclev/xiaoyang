电磁循迹小车：从传感器采集到闭环控制

从小白能理解的角度认识电磁循迹，再整理传感器、偏差计算、速度反馈与闭环调试的工程思路。

📅 2026-08-04🐑 小羊半夏⏱ 计算中
#项目#传感器#闭环控制

一、什么是电磁循迹

普通循迹小车通常用摄像头或红外传感器“看”道路，电磁循迹小车则通过电感传感器感知赛道周围的交变磁场。小车越偏离中心，不同位置传感器接收到的信号差异越明显，程序就可以据此判断应该向左还是向右修正。

可以把传感器想象成小车的“耳朵”：它们不是看见赛道，而是在听赛道发出的磁场声音。

二、系统由哪些部分组成

  • 主控：采集信号、计算偏差并输出控制量。
  • 电感传感器：把磁场变化转换成可以测量的电压。
  • 编码器：反馈车轮实际转速。
  • 电机驱动：把主控的小功率信号转换成驱动电机所需的电流。
  • 机械结构：轮胎、重心、传感器安装高度都会影响最终效果。

三、从传感器数据得到偏差

最简单的思路是给不同位置传感器设置权重。左侧传感器权重为负，右侧为正，再根据各传感器幅值计算加权平均。结果接近零表示小车位于中心，负值表示偏左，正值表示偏右。

偏差 ≈ Σ（传感器值 × 位置权重）÷ Σ传感器值
注意：正式计算前通常需要做零点校准、幅值归一化和异常值限制，否则某一路传感器偏高会长期拉偏结果。

四、闭环控制为什么重要

只有偏差还不够。程序需要根据偏差调整方向，同时利用编码器反馈维持速度。方向控制关注“往哪边修正”，速度控制关注“实际跑得有多快”。两者同时工作，才构成完整闭环。

// 简化示意：不是可直接移植的完整工程
error = get_track_error();
steer = kp * error + kd * (error - last_error);
left_pwm  = speed_output - steer;
right_pwm = speed_output + steer;
last_error = error;

五、调试时先看什么

  1. 先确认传感器静止时是否稳定，左右移动时变化方向是否正确。
  2. 再确认编码器方向、计数和实际车轮方向一致。
  3. 低速验证转向符号，避免参数正确但左右电机加减方向写反。
  4. 最后逐步提高速度，并观察振荡、迟钝和出弯恢复能力。

常见现象与方向

  • 左右摆动：比例过大、微分不足、采样噪声或机械间隙明显。
  • 转弯反应慢：比例偏小、速度过高或传感器前伸距离不足。
  • 直线也不稳：左右电机差异、轮胎摩擦、传感器零点不一致。

六、项目真正训练的能力

电磁循迹项目的价值不只是“车跑起来”，而是学会把问题拆成硬件、采集、算法、执行机构和机械结构五个层面，并通过实验逐项排除。很多看似需要继续调 PID 的问题，根源其实在供电、安装或电机一致性。

学习总结：先保证数据可信，再谈算法；先保证方向正确，再追求速度。
